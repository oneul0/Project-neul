# 25. UI 네이밍 최신화

> 작업일: 2026-05-16
> 브랜치: `feature/ui-naming-update`

---

## 배경

백엔드·문서 전반의 `neul → gak` 이관 작업 이후 프론트엔드 UI 코드에 남아있던
구 프로젝트명 잔재를 제거했습니다.

---

## 변경 내용

### `frontend/src/app/page.tsx` — 랜딩 페이지 설명 문구

**변경 전**

```
늘 스트리머가 자신의 방송 채팅 흐름을 빠르게 파악하고,
악성 반응에 과몰입하지 않도록 돕는 실시간 심리 가드레일 대시보드입니다.
```

문장 첫 단어 "늘"은 구 프로젝트명입니다.
설명 내용도 현재 제공 기능(투표·룰렛·VOD 분석)을 반영하지 않았습니다.

**변경 후**

```
실시간 투표·도네이션 룰렛으로 방송을 풍성하게 하고,
VOD 채팅 분석으로 편집 후보 구간을 빠르게 찾을 수 있는 스트리머 전용 운영 도구입니다.
```

---

## 점검 범위

| 대상 | 결과 |
|------|------|
| `src/**/*.tsx` — "neul" / "늘" 문자열 | `page.tsx` 1건 수정 |
| `src/**/*.ts` — "neul" / "늘" 문자열 | 없음 |
| `layout.tsx` 메타데이터·헤더·푸터 | 이미 "각 Control" 적용됨 |
| `package.json` name 필드 | `"frontend"` — 서비스명 아님, 유지 |
