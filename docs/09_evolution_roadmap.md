# Project Neul 로드맵 및 구현 체크리스트

최종 업데이트: 2026-04-01

이 문서는 기존 `09_evolution_roadmap.md`와 `10_implementation_checklist.md`를 합친 최신 계획 문서입니다.

## 1. 현재 프로젝트 단계

현재는 "실시간 채팅 감정 분석 대시보드" 초안에서 한 단계 더 나아가,

- owner 전용 대시보드
- VOD 편집 후보 탐색
- 타임라인/하이라이트 시각화

까지 연결한 상태입니다.

즉 다음 단계의 핵심은 "기능 추가"보다 "신뢰도, 운영성, 사용감"을 높이는 것입니다.

## 2. 지금 가장 중요한 우선순위

### P0. VOD 분석 신뢰도 고도화

- 하이라이트가 시간대 전반에 고르게 잡히는지 검증
- 조용한 방송에서도 상대적으로 튀는 구간을 잘 찾는지 개선
- 추천 이유 문구를 더 사람 친화적으로 다듬기
- 편집자가 바로 쓸 수 있는 수준의 카드 UX 정리

### P0. 타임라인 사용성 개선

- 그래프와 하이라이트 레일 가시성 개선
- 겹치는 타임스탬프와 마커 문제 해결
- 선택된 하이라이트와 카드의 연결 강화
- 모바일 레이아웃 보정

### P1. VOD 완료/상태 안정성

- analyzer completion 이벤트 누락 케이스 더 줄이기
- status fallback 정교화
- timeline 저장 누락 시 관측성 개선

## 4. 중기 로드맵

### 4-1. 스트리머용 편집 보조 강화

- 추천 구간 필터링
- 반응 유형별 정렬
- 편집 포인트 설명 개선
- 전체 방송 흐름 요약 카드

### 4-2. AI 분석 고도화

- 라이브 분석과 VOD 분석의 공통 점수 모델 정리
- reaction label 정교화
- 요약형 설명 생성 품질 개선
- 필요 시 하이브리드 모델 검토

### 4-3. 성능/최적화

- Rust 최적화는 장기 과제로 유지
- 지금은 VOD 사용자 가치와 안정성 우선

## 5. 현재 기준으로 outdated 처리한 계획

아래 항목은 당장 실행 우선순위에서 뒤로 밀렸습니다.

- 공개 채널 탐색형 대시보드 강화
