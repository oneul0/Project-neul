# 🚀 늘(Neul) 프로젝트 발전 로드맵 (Evolution Roadmap)

현재 "늘" 프로젝트는 **고성능 NID 웹소켓 수집**, **Ollama 기반 실시간 7종 감정 분석**, 그리고 **상대적 스파이크 감지 하이라이트 엔진**까지 핵심 파이프라인이 완성된 상태입니다. 여기서 기술적/기능적으로 더 도약할 수 있는 포인트들을 3단계로 제안합니다.

---

## 1. 단기: 성능 최적화 및 AI 고도화 (Optimization & Hybrid AI)

### ⚙️ Rust Native 최적화 (NativeBridge 실현)
- **현재**: Java(JVM)에서 2초 단위 배칭과 필터링을 처리하여 CPU/메모리 부하 발생 가능.
- **발전**: 이미 준비된 `NativeBridge`를 실제 **Rust** 모듈과 연결하여, 채팅 필터링(스팸 제거) 및 압축 로직을 Zero-copy로 처리. JVM GC 정체 현상을 극적으로 줄여 수만 명급 대규모 방도 무난히 소화 가능.

### 🧠 Multi-LLM 하이브리드 전략
- **현재**: Ollama(Llama3) 단일 모델로 모든 분석 수행.
- **발전**: 
  - **Ollama**: 현재처럼 2초 단위의 고속 감정 점수 산출 담당.
  - **Gemini 1.5 Flash**: 1분 단위 또는 **하이라이트 발생 시점**에만 호출하여 "왜 이 시점에 열광/분노했는지"에 대한 **상황 요약 및 맥락 분석** 수행. (속도와 깊이의 조화)

---

## 2. 중기: 기능적 확장 및 사용자 경험 (Feature Expansion)

### 🎬 하이라이트-VOD 자동 매핑 엔진
- **현재**: 실시간 이미지(Thumbnail)와 감정 점수만 저장.
- **발전**: 스트리밍 종료 후 생성된 VOD의 타임라인과 하이라이트 시점을 자동 매칭. 사용자가 하이라이트 보드에서 클릭 시 해당 VOD 시점으로 즉시 점프하는 기능.

### 📊 어드밴스드 시각화 (Advanced Visualization)
- **현재**: 선형 차트와 기본적인 통계.
- **발전**:
  - **감정 히트맵(Emotional Heatmap)**: 방송 시간 전체의 감정 흐름을 한눈에 보는 컬러 그리드.
  - **실시간 여론 미터기**: '민심'의 변화를 자동차 계기판처럼 직관적으로 보여주는 UI.
  - **키워드 버블 월(Bubble Wall)**: 지금 가장 많이 언급되는 단어들이 감정 색상에 따라 튀어 오르는 시각 효과.

### 🗳️ 인터랙티브 커뮤니티 기능
- **현재**: 단순 채팅 수집 및 분석.
- **발전**: 분석된 키워드를 기반으로 LLM이 자동 투표(Poll)를 생성 (예: "방금 플레이에 대해 어떻게 생각하시나요? 1. 나이스 2. 아쉽다"). 시청자 반응에 실시간으로 개입하는 AI 자동 방장 기능.

---

## 3. 장기: 플랫폼화 및 생태계 확장 (Platformization)

### 🌎 멀티 플랫폼 통합 수집기
- **현재**: 치지직(Chzzk) 전용.
- **발전**: Twitch, YouTube 아프리카TV용 수집기(Collector)를 추가하여 **통합 스트리밍 분석 대시보드**로 진화. `common` 모듈의 데이터 규격이 이미 범용적이라 확장이 용이함.

### 🤖 개인화된 스트리밍 리포트 (Creator Insights)
- **현재**: 실시간 대시보드 위주.
- **발전**: 방송 종료 시 "오늘의 민심 리포트" 자동 생성. 가장 반응이 좋았던 구간, 채팅 화력이 집중된 시간, 시청자가 가장 많이 사용한 밈(Meme) 등을 PDF/Interactive UI로 제공.
